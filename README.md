# AR AWNING Contact Landing Page

A responsive React + Vite + JavaScript + Tailwind CSS contact landing page inspired by the supplied reference screenshot.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Update contact details

Edit `src/App.jsx`:
- `WHATSAPP_NUMBER` uses international format without `+` or spaces.
- `WEBSITE_URL` is the official website destination.

The supplied logo is stored at `public/ar-fair-trading-logo.webp`.
